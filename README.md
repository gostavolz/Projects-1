# Projects-1 🗄️
Laboratório de estudos focado nos fundamentos de banco de dados estruturados e SQL.

## 📝 Descrição
Este repositório armazena meus primeiros passos com banco de dados relacionais, contendo scripts de teste, criação de tabelas, consultas e manipulação de dados utilizando o **SQL Server**.

## 🛠️ Conceitos Aplicados
* Comandos fundamentais de SQL (DDL e DML)
* Estruturação de tabelas e definição de tipos de dados
* Integração teórica e prática com o ambiente SQL Server
